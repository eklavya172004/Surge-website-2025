# CART

In your cart page:

1. For each cart item, create a team using createTeamWithMembers
2. Display each created team with a "Pay Now" button
3. When user clicks "Pay Now", call calculateTeamAmount to show the amount
4. After payment, call finalizeTeamPayment with the transaction ID

5. Benefits of This Approach

6. Granular Control: Users can pay for teams individually
7. Better UX: Users don't have to pay for everything at once
8. Flexibility: Users can abandon some teams without affecting others
9. Clear Tracking: Each team has its own payment record
